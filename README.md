# Sahil Birari — Portfolio

A responsive, three-page portfolio focused on Data Analytics, Data Engineering and Cloud Engineering.

## Pages

- Home — positioning, selected work and core strengths
- Projects — detailed case-study summaries and repository links
- About — experience, education, leadership and technical toolkit

## Publish with GitHub Pages

1. Push this repository to GitHub using the `main` branch.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The included workflow will deploy the `dist` folder automatically.

No build step or dependencies are required.
